# Prompt archive and provenance

Files under `originals/` are copied from the named user-provided prompt attachments. Machine-specific project roots are replaced with `<PROJECT_ROOT>`, and row-level identifiers are replaced with typed placeholders where they appeared. They are redacted copies, not byte-for-byte originals. Review before redistribution.

The initial project did not contain a complete prompt archive. Phase 1, Phase 3, Phase 5, Phase 6, Phase 9A, Phase 9B, Phase 9D, and Phase 11A were supplied in conversation rather than the available attachment files. `reconstructed_phase_overview.md` summarizes those objectives from the project artifacts; it is reconstructed and must not be represented as verbatim prompt text.
